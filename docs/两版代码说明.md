## 两版分别下载与运行

在本机空目录中分别克隆，避免来回切版本误用同一个数据库：

```bash
git clone --branch baseline-v1 https://github.com/cql123-love/CampusEvent.git CampusEvent-v1
git clone --branch change-v2 https://github.com/cql123-love/CampusEvent.git CampusEvent-v2
```

各目录分别建立虚拟环境并执行 `pip install -r requirements.txt`、`python app.py`；一次运行一版，停止后再运行另一版。初版没有 `seed.py`，设置 `PORT=5000` 后启动才按原逻辑生成演示数据。数据库互相独立，不把迁移后的新库交给旧代码运行。Windows 环境示例：

```powershell
cd CampusEvent-v1
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe -m pytest tests -v
$env:PORT="5000"
.\venv\Scripts\python.exe app.py
```

新版对 `CampusEvent-v2` 执行同样命令。两版原测试均可重跑；`python tools/verify_release.py` 还会自动从初版标签解包测试并生成对照证据。
