此前的平台方案因注册、额度或账号条件未完成，不代表已部署。最终使用用户自行创建的腾讯云 Ubuntu 实例。

免费试用并非永久免费。试用到期日、流量和磁盘费用、续费设置需由账号持有人在控制台确认；仓库及部署脚本不代为开启付费项目。
