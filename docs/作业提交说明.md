### 关于免费部署平台的选择

最初尝试用 Railway，但 Railway 免费计划**每个账号仅允许 1 个免费项目**（第二个需付费升级）。
之前尝试过 Render，但没有取得可验证的公网地址。下表是历史选型记录，不代表已部署；当前准备使用 PythonAnywhere 免费账户的持久目录方案。

历史记录：

| 维度 | Railway Free | **Render Free（采用）** |
|---|---|---|
| 信用卡 | 免卡 | **免卡** |
| 账号可建免费项目数 | **1 个** | **多个**（共享 750 实例小时/月） |
| 免费额度过期 | $5 试用 30 天 → $1/月 | **无过期**，持续免费 |
| 休眠 | 可选 | 15 分钟无访问休眠（约 1 分钟唤醒）|

仓库内 `render.yaml` 与 `railway.json` 两套配置都保留，README 第四章记录了各平台的部署步骤，任一平台均可复现。

## 四、老师复现路径

```bash
git clone https://github.com/cql123-love/CampusEvent.git
cd CampusEvent
python -m venv venv && venv\Scripts\activate      # Windows
pip install -r requirements.txt
python app.py        # http://127.0.0.1:5000
pytest tests/ -v    # 22 条验收用例
```

或直接访问线上地址（见答案栏第二行）。
